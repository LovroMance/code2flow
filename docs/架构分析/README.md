# Code2Flow 项目分析交付

- [分析报告](./分析报告.md)：架构、目录、锁定技术栈、功能链路、完成度、验证与改进优先级。
- [图表总览](./图表总览.html)：双击即可离线查看，12 张图支持缩放和 SVG 下载。
- [源码索引](./源码索引.md)：各图和关键结论对应的源文件位置。
- [验证记录](./验证记录.json)：实际检查结果与未执行项目。
- `diagrams/*.mmd`：12 份可编辑 Mermaid 源图。
- `diagrams/*.svg`：12 张可直接插入文档或演示材料的矢量图。

图表主题依次为：系统总体架构、目录结构、前端依赖、后端分层、生成时序、graph 状态与重试、SSE 状态、节点定位、追问时序、数据关系、观测评估、运行拓扑。

分析基于 2026-10-19 当前工作区，不覆盖此前已有报告，不改动业务代码。根目录和双端脚本的验证结果在报告中列明。

## 图表维护

`build-diagrams.cjs` 内维护图源、标题、说明与图集样式。默认执行 `node docs/架构分析/build-diagrams.cjs` 会导出 Mermaid 源码，并把已有 SVG 内嵌为离线图集。

修改图源后，执行 `node docs/架构分析/build-diagrams.cjs --render`，在浏览器打开新图集；此模式使用仓库现有 `node_modules/mermaid/dist/mermaid.min.js` 实际渲染。逐图下载 SVG 覆盖对应导出文件后，再执行默认命令生成离线版。图源变化必须重新渲染，不能沿用旧 SVG。
