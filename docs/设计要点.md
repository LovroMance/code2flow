# Code2Flow 重新设计要点

本文记录重新设计期间的决策与要点，按编号逐条追加。

## 1. Agent 工具调用单独封装

### 决策

Agent 的工具（tools）必须从业务逻辑中隔离出来，单独封装：

- **一个 tool 一个文件**，放在 `backend/src/ai/tools/`。
- 工具层与业务层解耦，工具不依赖具体的 service 实现、编排流程或会话状态管理。
- 工具视为**可插拔单元**：后续新增其他 agent 时，可以直接复用同一批工具文件，而不必复制或改写业务代码。

### 动机

当前工具与业务逻辑混在一起，导致三个问题：

1. **耦合**：工具执行体内联在服务类中，与证据登记、计量、预算等业务状态绑死，无法独立复用。
2. **不可复用**：新增 agent 需要工具时，只能重新实现或绕过，容易产生第二套行为不一致的实现。
3. **不可独立验证**：测试单个工具必须构造完整的业务上下文。
