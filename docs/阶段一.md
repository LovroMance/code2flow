# 阶段一：Code2Flow MVP 规划

## 项目名称

Code2Flow - 代码转流程图 Agent

## 项目概述

开发一个 Vue 3 + TypeScript + LangChain.js 的 AI Agent 应用，用户输入主流编程语言代码，Agent 自动分析代码的控制流，生成 Mermaid 流程图，并支持点击节点跳转到对应代码行。2026-10-21 扩展产品范围：不再局限前端，语言清单以 `backend/src/domain/flow/language.ts` 为准，Vue 特有逻辑继续支持。

## 目标用户

各语言开发者、代码 Reviewer、接手老项目的开发者

## 阶段目标

完成一个可演示、可闭环的首版产品，让用户能够输入代码、生成流程图、查看节点与代码行映射，并通过点击节点快速定位代码逻辑。

## 核心功能（阶段一）

1. 代码编辑器（Monaco Editor）支持用户输入 / 粘贴代码
2. Agent 自动分析代码，生成 Mermaid 流程图
3. 流程图实时渲染，支持缩放、拖拽
4. 点击流程图节点，编辑器自动高亮对应代码行
5. 流式输出：Agent 边生成边渲染

## 技术栈

### 前端

- Vue 3 + TypeScript + Vite
- Monaco Editor（代码编辑）
- Mermaid.js（流程图渲染）
- @langchain/vue（流式状态管理）
- TailwindCSS（样式）

### 后端

- Node.js + Express + TypeScript
- @langchain/langgraph（Agent 编排）
- @langchain/openai（LLM 调用，支持 DeepSeek API）
- zod（结构化输出校验）

## Agent 技术要求

### 阶段一必须实现的 Agent 能力

1. **结构化输出**：使用 Zod + Function Calling 强制 LLM 输出 JSON，包含 Mermaid 代码和节点到代码行的映射
2. **Few-shot Learning**：在 Prompt 中提供 2-3 个代码到流程图的示例
3. **Self-Correction**：验证 Mermaid 语法，出错时自动重试（最多 3 次）
4. **流式输出**：SSE 逐块返回生成的流程图

### 阶段一 LangGraph 状态图设计

定义以下节点和边：

- `analyze` 节点：调用 LLM 分析代码，生成 Mermaid 和映射
- `validate` 节点：校验 Mermaid 语法
- 条件边：`validate` 失败且重试次数小于 3 时回到 `analyze`

## 前端技术要求

### 阶段一必须实现的前端能力

1. **Monaco Editor 集成**：语法高亮、代码折叠、自动布局
2. **Mermaid 渲染**：动态渲染流程图，支持暗色主题
3. **点击联动**：点击流程图节点，Monaco Editor 滚动并高亮对应行
4. **流式状态管理**：使用 `@langchain/vue` 的 `useStream` Hook
5. **防抖处理**：用户停止输入 500ms 后触发 Agent 生成
6. **响应式布局**：左右分栏可拖拽调整宽度

## Prompt 模板要求

### 系统 Prompt

你是一个前端代码分析专家。分析以下代码，生成 Mermaid 流程图和节点到代码行的映射。

输出必须是严格的 JSON 格式：

```json
{
  "mermaid": "flowchart TD\n A[开始] --> B{判断}",
  "mappings": [
    {
      "nodeId": "A",
      "lineStart": 1,
      "lineEnd": 1,
      "description": "开始"
    },
    {
      "nodeId": "B",
      "lineStart": 3,
      "lineEnd": 5,
      "description": "条件判断"
    }
  ]
}
```

规则：

- 提取 `if / else`、循环、函数调用、异步操作（`Promise` / `async-await`）
- 用 `flowchart TD` 语法
- 每个节点标注行号范围
- Vue / 通用前端专项：
  - `onMounted`、`onUnmounted` 画成生命周期节点
  - `watch`、`watchEffect` 画成响应式副作用节点
  - `ref`、`reactive` 的关键状态更新画成状态节点
  - `computed` 画成派生数据节点
- 只输出 JSON，不要其他内容

### Few-shot 示例

输入代码：

```js
async function loadUser() {
  const user = await fetchUser()

  if (user.isActive) {
    goToDashboard()
  } else {
    showInactiveMessage()
  }
}
```

输出：

```json
{
  "mermaid": "flowchart TD\n A[开始] --> B[fetchUser]\n B --> C{user.isActive?}\n C -->|是| D[goToDashboard]\n C -->|否| E[showInactiveMessage]",
  "mappings": [
    {
      "nodeId": "A",
      "lineStart": 1,
      "lineEnd": 1,
      "description": "函数开始"
    },
    {
      "nodeId": "B",
      "lineStart": 2,
      "lineEnd": 2,
      "description": "异步获取用户"
    },
    {
      "nodeId": "C",
      "lineStart": 4,
      "lineEnd": 4,
      "description": "判断用户是否激活"
    },
    {
      "nodeId": "D",
      "lineStart": 5,
      "lineEnd": 5,
      "description": "跳转仪表盘"
    },
    {
      "nodeId": "E",
      "lineStart": 7,
      "lineEnd": 7,
      "description": "显示未激活提示"
    }
  ]
}
```

## API 接口定义

### `POST /api/generate-flow`

请求体：

```json
{
  "code": "string",
  "thread_id": "string"
}
```

说明：

- `code`：用户输入的代码
- `thread_id`：会话 ID，可选；首版可保留字段，但主要用于后续增强能力扩展

响应：SSE 流

```text
data: {"type": "mermaid", "content": "flowchart TD..."}
data: {"type": "mappings", "content": [...]}
data: {"type": "done"}
```

## 面试话术（项目介绍）

“我做了一个代码转流程图 Agent，叫 Code2Flow。输入 JavaScript、TypeScript 或 Vue 前端代码，Agent 会自动分析控制流、条件分支和异步逻辑，生成 Mermaid 流程图。

Agent 层面，我用了 LangGraph 做状态编排，实现了 Few-shot 和 Self-Correction。比如检测到 Mermaid 语法错误会自动重试，最多 3 次。

前端层面，集成了 Monaco Editor 和 Mermaid，做了双向联动：点击流程图节点，编辑器会自动滚动并高亮对应代码行。

这个项目解决的是：接手老项目时理解复杂逻辑太费时间，用 AI 可视化后效率明显提升。”

## 阶段一验收标准

1. 能处理 50-500 行的 JavaScript / TypeScript / Vue 代码
2. 正确识别 `if / else`、`for / while`、函数调用、`Promise` / `async-await`
3. Mermaid 语法正确，能正常渲染
4. 点击节点能高亮正确代码行
5. 流式输出体验流畅
