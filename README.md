# Code2Flow

Code2Flow 是一个将 JavaScript、TypeScript、Vue 前端代码转换为 Mermaid 流程图的 Agent 项目。

## 当前结构

- `frontend/`：Vue 3 + Vite 前端骨架
- `backend/`：Express + TypeScript 后端骨架
- `docs/`：阶段规划、Prompt 规范、脚本规划
- `AGENTS.md`：项目协作规则

## 启动前准备

当前仓库已经具备基础目录和脚本，根目录已启用 npm workspaces，先在根目录安装一次依赖即可：

```bash
npm install
```

## 常用命令

```bash
npm run dev
npm run build
npm run check
```
